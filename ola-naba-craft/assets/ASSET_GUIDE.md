# Asset guide

- logo.svg / logo.png: Original vector logo and 1800×540 transparent PNG. Available for title screens and launch art.
- icon.svg: Twin-color isometric block, no external artwork.
- ola.svg / naba.svg: Original menu badge illustrations with matching visual identities.
- references/Ola-navy.jpeg and references/Naba-pink.jpeg: User-supplied pixel art, private references only; excluded from Godot asset import by .gdignore. Do not copy any commercial garment graphics into final in-game art. Keep only original assets in release distribution.
- The starter's editable 3D avatars are code-built from box meshes. Its terrain uses original generated palette textures. No external game assets or add-ons.
